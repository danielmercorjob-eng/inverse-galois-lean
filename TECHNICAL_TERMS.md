# Project terms

The English text uses the writing rules and dictionary of [ASD-STE100 Issue 9](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf).
The tables give the meanings of technical nouns and technical verbs for mathematics and software.
Code identifiers, commands, formulas, and file names keep their source spelling.

## Technical nouns

| Term | Meaning in this project |
|---|---|
| Algorithm | A finite procedure to calculate a result |
| API | The functions and input fields that a caller can use |
| Axiom audit | A check of the axioms in a Lean declaration |
| Backend | The GAP process and its HAP operations |
| Betti number | The dimension of H^n(G,Fp) with trivial coefficients |
| Bogomolov multiplier | The group B0(G) in the Lean definition |
| Character | The character of a complex representation |
| Class sum | A sum with one term for each conjugacy class |
| Command | An instruction for a computer program |
| Commit | A recorded version of the project files |
| Compilation | The compiler process for a source file |
| Conjugacy class | A class of group elements under conjugation |
| Declaration | A named Lean definition, instance, or theorem |
| Group file | A JSON file that defines a permutation group |
| Invariant factors | Cyclic factors in divisibility order |
| McKay arrow multiplicity | The dimension of Hom_G(rho_j,V tensor rho_i) |
| Molien series | The determinant sum in the Lean definition |
| Natural permutation representation | The representation from the action in the group file |
| Regular representation | The representation from the group action on itself by multiplication |
| Resolution | A group resolution in homological algebra |
| Schur multiplier | The group H_2(G,Z) |
| Timeout | The end of a time limit for a process |
| Toolchain | The compiler and its related programs |
| Trivial group | A group with one element |
| Unit index | The index of the trivial representation |
| Variant | A generated statement for one set of input options |

The mathematical nouns also include their usual parts and properties.
Examples include cohomology, homology, cocycle, quotient, tensor product, isomorphism, coefficient, kernel, duality, and finite dimensionality.
The software nouns include file, directory, module, import, library, script, executable, tuple, string, JSON, and process.
Proper names include Python, Lean, Mathlib, GAP, HAP, Sage, PSL27, and M23.

## Technical verbs

| Verb | Meaning in this project |
|---|---|
| Compile | Use a compiler on a source file |
| Define | Give a mathematical definition |
| Divide | Be an integer divisor of another integer |
| Expand | Write a polynomial as a sum of monomials |
| Prove | Give a mathematical proof by deduction |
| Serialize | Write data in a specified data format |
| Verify | Find if a formal proof or a computed result is correct |

The technical verbs have only the meanings in this table.
General instructions use approved verbs such as calculate, compare, read, select, start, and write.
